# Atlantic Blue Coast Realty

A fullstack real estate web application for Atlantic Blue Coast Realty LLC, built with Angular (frontend) and Node.js (backend).

---

## Monorepo Structure

```
Atlantic-Blue-Coast-Realty/
│
├── client/    # Angular frontend (SPA)
├── server/    # Node.js backend (API, mailer, etc.)
├── README.md  # (this file)
└── .gitignore
```

---

## Getting Started

### Prerequisites

- Node.js (v10+ recommended)
- npm (v6+ recommended)

### 1. Clone the repository

```sh
git clone https://github.com/yourusername/Atlantic-Blue-Coast-Realty.git
cd Atlantic-Blue-Coast-Realty
```

### 2. Install and Run the Backend

```sh
cd server
npm install
npm start
# Backend runs on http://localhost:4040
```

### 3. Install and Run the Frontend

```sh
cd ../client
npm install
ng serve
# Frontend runs on http://localhost:4200
```
